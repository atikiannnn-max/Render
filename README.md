# Render — глазурованная керамика

Кружка создаётся в **Blender** (`blender/build_cup.py`) и экспортируется в GLB
с Draco-сжатием. Браузерная страница — это лёгкий Three.js-вьювер, который
только показывает готовый ассет: студийный свет, мягкие тени и выбор глины.

![Серо-бежевая глина](docs/hero.png)

## Что сейчас в кадре

- Два варианта глины: тёплая ivory/warm stone и тёмная «асфальт».
- Сцена — минималистичный cyclorama: бесшовный средне-серый фон и пол,
  высокая roughness, почти без отражений.
- Прозрачная глянцевая глазурь: полностью внутри чашки и на выступающем
  круглом рельефе (~1.8 мм); наружная матовая стенка глазурью не покрыта.
  Материал экспортируется как KHR_materials_clearcoat.
- Круглый барельеф встроен в геометрию стенки, а маска глазури использует ту
  же конфигурацию рельефа — покрытие ложится точно на выпуклость.
- Студийный свет: крупные area-софтбоксы (ключ сверху-слева/спереди, заливка
  справа/спереди, верхний и контровой), мягкая широкая тень уходит в сторону,
  противоположную основному свету.

## Запуск страницы

Не открывайте `index.html` двойным кликом — WebGL-модули и GLB не работают по
`file://`. Запускайте сервер:

```bash
npm install
npm run dev
```

Продакшн-сборка:

```bash
npm run build
npm run preview
```

Единственная runtime-зависимость — [`three`](https://www.npmjs.com/package/three).
Опубликованная версия живёт на GitHub Pages.

## Пересборка GLB из Blender

```bash
"/Applications/Blender.app/Contents/MacOS/Blender" -b -y --python blender/build_cup.py -- --clay stone
"/Applications/Blender.app/Contents/MacOS/Blender" -b -y --python blender/build_cup.py -- --clay asphalt
```

Скрипт строит mesh со слоями печати и рельефом, генерирует карты глины/
глазури и экспортирует `public/models/cup-*.glb`. При желании сам `.blend`-
файл можно открыть в Blender и дорабатывать модель вручную.

## Структура

```
blender/
  build_cup.py       headless-генератор модели и текстур в Blender
public/
  models/cup-*.glb   готовые ассеты (Draco)
  textures/          карты глины/глазури
  draco/             декодер для GLB
src/
  main.js            Three.js-вьювер: свет, тени, выбор глины
```
